# 📊 HR Analytics Dashboard – Overview

## 📌 Project Description
This project showcases the **Overview page of a Human Resources Analytics Dashboard** built to provide high-level insights into workforce data. It helps HR managers quickly understand hiring trends, employee distribution, and organizational structure.

---

## 🎯 Objective
- Track overall hiring and termination trends  
- Provide a snapshot of employee distribution  
- Analyze department-wise workforce allocation  
- Visualize geographic distribution of employees  

---

## 📊 Dashboard Features

### 🔹 Key Performance Indicators (KPIs)
- Total Hired Employees: **8,950**  
- Active Employees: **7,984**  
- Terminated Employees: **966**  

---

### 🔹 Hiring & Termination Trends
- Year-wise visualization of:
  - Employees hired  
  - Employees terminated  
- Helps identify workforce growth and attrition patterns  

---

### 🔹 Department Distribution
- Employees categorized by department:
  - Operations  
  - Sales  
  - Customer Service  
  - IT  
  - Marketing  
  - Finance  
  - HR  
- Enables comparison of team sizes across departments  

---

### 🔹 Location Analysis
- Employee distribution across:
  - States  
  - Cities  
- Comparison between:
  - Headquarters (New York)  
  - Branch locations  

---

## 🗂️ Dataset Information
- Total Records: **8,950 employees**  
- Data includes:
  - Employee ID  
  - Department  
  - Location  
  - Hire Date  
  - Termination Date  

---

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard visualization  
- **Python (Pandas, NumPy)** – Data generation & preprocessing  
- **Excel / CSV** – Data storage
